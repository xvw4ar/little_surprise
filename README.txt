NIGHT CITY BIRTHDAY WEBSITE

UPLOAD:
1. Extract this ZIP.
2. Upload index.html and the assets folder to the ROOT of your GitHub Pages repository.
3. When you have the song file, put it inside assets and name it exactly: birthday-song.m4a
4. The audio player expects: assets/birthday-song.m4a

The interface click sounds are generated by the page itself. No separate sound file is needed.
